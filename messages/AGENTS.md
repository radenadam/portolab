# Messages

Each phrase that recurs in errors has one translation in each language, so that every error states its rule in the same way and both languages say the same thing. An error that repeats a phrase of another error takes it from this table, and a change that gives a phrase its second use adds its row.

| English                                                      | Bahasa Indonesia                                       | Use                                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------- |
| The field "X" ...                                            | Kolom "X" ...                                          | The subject of an error about a field.                                      |
| The field "X" takes ...                                      | Kolom "X" menerima ...                                 | The rule of what a field accepts.                                           |
| The field "X" takes A to B ...                               | Kolom "X" menerima A sampai B ...                      | The range of values or lengths that a field accepts.                        |
| The field "X" holds at most ...                              | Kolom "X" memuat paling banyak ...                     | The largest value or length of a field.                                     |
| The field "X" needs at least ...                             | Kolom "X" perlu paling sedikit ...                     | The smallest value or length of a field.                                    |
| The field "X" holds "V", but ...                             | Kolom "X" berisi "V", tetapi ...                       | A value that a person typed, stated as a fact before what is wrong with it. |
| ..., but it holds "V".                                       | ..., tetapi isinya "V".                                | The value of a field against its rule.                                      |
| ..., but it has N.                                           | ..., tetapi isinya N karakter.                         | The length of a field against its rule.                                     |
| ..., such as E.                                              | ..., misalnya E.                                       | An example of a value or of a next step.                                    |
| The form sent ... in the field "X" ...                       | Formulir mengirim ... di kolom "X" ...                 | A value that only a broken or forged form sends.                            |
| ... a value of type T in the field "X" instead of text.      | ... nilai bertipe T di kolom "X", bukan teks.          | A value of a form that is not text.                                         |
| ... in the language switch.                                  | ... di pengalih bahasa.                                | The control that chooses the language.                                      |
| ... and try again.                                           | ..., lalu coba lagi.                                   | A step before the next attempt.                                             |
| the code of a class                                          | kode kelas                                             | The code with which a student joins a class.                                |
| this username                                                | nama pengguna ini                                      | The username that the error is about.                                       |
| Check the code with your lecturer                            | Periksa kodenya dengan dosen Anda                      | A code of a class that is wrong.                                            |
| Only X ..., and you are signed in as Y.                      | Hanya X yang ..., dan Anda masuk sebagai Y.            | An action that the role of the reader does not allow.                       |
| Portolab blocks ...                                          | Portolab memblokir ...                                 | A block on attempts.                                                        |
| ... for a while.                                             | ... untuk sementara.                                   | A block that ends by itself.                                                |
| N wrong X                                                    | N X salah                                              | The attempts that a block counts, such as wrong passwords or wrong codes.   |
| After N wrong attempts within M minutes, Portolab ...        | Setelah N percobaan salah dalam M menit, Portolab ...  | A limit on attempts, before the reader reaches it.                          |
| ... until T WIB, because it received N ... within M minutes. | ... sampai T WIB, karena menerima N ... dalam M menit. | A block or a limit that the reader reached, and when it ends.               |
| ... from your network ... from it ...                        | ... dari jaringan Anda ... dari jaringan itu ...       | The network that a block or a limit counts.                                 |
| The block stops anyone who tries to ...                      | Blokir ini menghentikan siapa pun yang mencoba ...     | Why a block exists.                                                         |
| The limit stops anyone who tries to ...                      | Batas ini menghentikan siapa pun yang mencoba ...      | Why a limit exists.                                                         |
| Try again after that time.                                   | Coba lagi setelah waktu tersebut.                      | The next step after a block or a limit.                                     |
